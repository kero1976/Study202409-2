# 1.インストール

NuGetで「StyleCop.Analyzers」バージョン1.1.118(2026/10現在最新)をインストールする。

# 2.警告を無視

1. ソリューションを選択し、[追加]-[新しい項目の追加]で、「Code Analysis規則セット」(旧：Code分析規則セット)を選択する。
2. ファイルを開いて、「StyleCop.Analyzers」を展開し、該当ルールの操作を「非表示」にする。
3. プロジェクトのプロパティで「Code Analysis」(旧：コード分析)を選択し、規則セットの構成でアクティブな規則に作成したファイルを指定する。

# 3.無視する警告

| コード | 説明                                      | 無視する理由         |
| :----- | :---------------------------------------- | :------------------- |
| SA1200 | usingの位置はnamespaceの中                | 標準のままでOKとする |
| SA1629 | XMLドキュメントがピリオドで終わっていない | 日本語表記のため不要 |
| SA1633 | 標準ファイルヘッダーが無い                | 必要なし             |
